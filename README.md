# Requirements 
* Visual Studio 2022
* Microsoft Visual C++ (Should be installed together with Visual Studio 2022)

# Compilation 
Compile using the developer command prompt from Visual Studio 2022 and the .cpp file

Tutorial:
1. Navigate to the file directory containing the .cpp
2. Use `cl /EHsc helloWorld.cpp`
   
The previous command will create helloWorld.exe

# Running the Program
Call the compiled .exe with **helloWorld** in the command line

Output will be
`Hello World`
